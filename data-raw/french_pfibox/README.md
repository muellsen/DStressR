# French PFIbox Source Data

This directory is reserved for local source and processed files from French,
Coutts, and Brown (2018), *Cell Systems*, doi:10.1016/j.cels.2018.07.004.

The paper's deposited data are listed as Mendeley Data
doi:10.17632/fmv6vv4bsf.1. The public GitHub repository
`sfrench007/pfibox` also contains scripts and sample ImageJ output files.

Large raw files are intentionally kept out of Git. Place downloaded source
files under:

```text
data-raw/french_pfibox/source/
```

Derived compact tables are written to:

```text
data-raw/french_pfibox/processed/
```
