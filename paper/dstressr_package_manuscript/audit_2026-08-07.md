## Code And Math Consistency

- `prepare_assay()` computes the response as
  `log2(lux + pseudocount) - alpha * log2(growth + pseudocount)`.
- The package default pseudocount is `1e-8`; application scripts can override
  this when a strictly positive summarized response makes it unnecessary.
- Response-level EV/background calibration is implemented before effect
  estimation and excludes the background reporter from downstream testing.
- The default inferential target is the centered promoter-specific effect.
- Empirical-Bayes moderation changes standard errors, test statistics, p-values,
  and adjusted p-values; it does not change fitted effects.
- Low-rank adjustment is implemented as a signed SVD of the total-effect matrix.
  It is a sensitivity analysis, not the default workflow.
- Rank-adjusted total-effect inference is conditional on the estimated low-rank
  component; low-rank estimation uncertainty is not added to the standard error.
